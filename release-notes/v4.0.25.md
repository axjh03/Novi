What's new in Novi

Getting ready
• Run Get ready again any time with the new button at the top of session setup.
• At the start of a session, the ready check names anything that isn't ready yet.
• Screen and system audio problems on Windows and Linux now come with steps you can actually follow.

Clearer messages
• If an API key stops working, Novi says who can fix it. Keys from your Novi account are replaced by your Novi admin in the web portal.

Phone companion
• It starts only when you open it, and a new link is made each time. Signing out disconnects your phone.
• With Anywhere on, it only accepts the secure tunnel connection.

Conversations
• Save a conversation to a file, and rename conversations.

Updates and security
• Windows updates install reliably again. If an update doesn't finish, download Novi once from the website.
• Safer PDF reading and several security improvements.
